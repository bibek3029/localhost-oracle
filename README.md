# 🔮 Localhost Oracle

Localhost Oracle is a small local AI application that turns filesystem metadata into a playful fortune.

It scans selected folders on your computer, calculates simple statistics about the files it finds, and uses Tether's QVAC SDK to generate a short creative phrase locally on the device.

## What It Does

Localhost Oracle scans these folders by default:

- `~/Downloads`
- `~/Desktop`
- `~/Documents`

The scanner collects filesystem metadata such as:

- Number of files
- File extensions
- File sizes
- Modification timestamps
- Folder depth
- Filename patterns such as `final_v1`, `final_v2`, etc.

The application does **not** read the contents of the files.

The collected metadata is aggregated into statistics such as:

- Total files scanned
- Deepest folder level
- Most common file type
- Number of files of the most common type

These statistics are then combined with a short creative phrase generated by a local QVAC model.

## How QVAC Is Used

Localhost Oracle uses Tether's QVAC SDK with:

- `loadModel()`
- `completion()`
- `unloadModel()`

The QVAC model is used locally to generate the creative phrase used by the Oracle.

The factual filesystem statistics are calculated by JavaScript rather than generated by the AI model. This keeps the factual information deterministic while still using local AI for the creative part of the experience.

The application uses the `LLAMA_3_2_1B_INST_Q4_0` QVAC model.

## Privacy

Localhost Oracle is designed around local processing.

By default, the scanner reads filesystem metadata rather than file contents.

The application does not send the scanned metadata to a remote AI API.

QVAC inference runs locally on the device.

## Requirements

- Node.js 22 or newer
- npm
- A machine supported by the QVAC SDK
- `@qvac/sdk` version `0.19.1`
